# Medical-Procurement-Analytics-Dashboard
An interactive Power BI dashboard developed to analyze and monitor medical procurement operations, supplier performance, purchasing costs, inventory movement, and procurement efficiency within the healthcare sector. The dashboard provides real-time insights that support strategic purchasing decisions, cost optimization, and supply chain management.

## Key Features
- Procurement cost and spending analysis
- Supplier performance monitoring
- Medical inventory and stock tracking
- Purchase order and delivery analysis
- Department-wise procurement insights
- Trend analysis for medical supplies and equipment
- Interactive filtering and drill-down reporting

## KPIs Included
- Total Procurement Cost
- Total Purchase Orders
- Supplier Performance Rate
- Inventory Availability
- Average Delivery Time
- Procurement Efficiency Rate

## Tools & Technologies
- Power BI
- Excel
- DAX
- Data Cleaning & Transformation
- Business Intelligence Reporting
- Business Impact

This dashboard helps healthcare organizations improve procurement efficiency, monitor supplier reliability, reduce operational costs, prevent stock shortages, and enhance data-driven decision-making across medical supply chain operations.
